# Xbox 控制器 MQTT 转发工具 (Python)

本项目通过 Python 实时读取 Xbox 手柄数据，并将其封装为 JSON 格式通过 MQTT 协议发布。适用于远程控制机器人、无人机或各类物联网设备。

## 🛠️ 环境准备

### 1. 硬件需求

* **手柄连接**：运行脚本前必须连接手柄（如 Xbox One/Series 控制器）。脚本通过 `pygame` 识别手柄硬件。

### 2. 依赖库安装

确保已安装 `pygame`（处理输入）和 `paho-mqtt`（处理通信）：

```bash
pip install pygame paho-mqtt

```

### 3. MQTT Broker 配置

脚本默认连接至本地 Broker：

* **地址**：`localhost`
* **用户**：`myuser` / **密码**：`123`

> [!TIP]
> 如果你已使用 **NSSM** 注册了 Mosquitto 服务，请确保服务已启动且配置文件中的用户与脚本匹配。

---

## 📖 使用指南

### 1. 运行脚本

直接运行 `mqtthello.py`：

```bash
python mqtthello.py

```

脚本将以 **30Hz** 的频率发布数据至主题：`controller/xbox`。

### 2. 数据格式说明

发布的数据为 JSON 格式，包含摇杆、扳机及常用按键信息：

```json
{
    "lx": 0.0, "ly": 0.0,  // 左摇杆坐标
    "rx": 0.0, "ry": 0.0,  // 右摇杆坐标
    "rt": -1.0,            // 右扳机 (RT)
    "btnA": 0, "btnB": 0,  // A, B 按钮 (0为松开, 1为按下)
    "btnX": 0, "btnY": 0   // X, Y 按钮
}

```

## ⚙️ 代码重构与 GUI 调试建议

为了提升调试体验，建议将当前的纯命令行脚本重构为 **带有 GUI 界面的调试工具**（可使用 `Tkinter` 或 `PyQt`）。

### 为什么需要 GUI 重构？

* **安全解锁机制**：在发送控制指令前，通过界面上的“安全开关”手动解锁，防止手柄误触导致设备失控。
* **可视化监控**：实时显示当前手柄的轴数值，无需订阅 MQTT 即可确认输入是否线性。
* **动态调参**：在界面上直接修改 `BROKER` 地址或发布频率 `FREQ`，无需反复重启代码。

### 重构思路逻辑图

### 建议重构模块：

1. **控制模块 (`ControllerThread`)**：将 `pygame` 的轮询逻辑放入后台线程，避免阻塞界面。
2. **通信模块 (`MqttClient`)**：管理连接状态。
3. **UI 模块 (`Dashboard`)**：
* **Status Bar**：显示 MQTT 连接状态和手柄连接状态。
* **Sliders**：用进度条（ProgressBar）展示摇杆的偏移量。
* **Unlock Button**：设置一个大红色的“解锁”按钮，只有点击后才开始向 MQTT 发布真实数据。
